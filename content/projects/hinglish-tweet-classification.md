### Project Context
Code-mixed languages such as Hinglish (Hindi written using the Latin alphabet) present significant NLP challenges due to informal phonetics, lack of standard spelling rules, and dialectal variations.

### Implementation
- Preprocessed raw social media data with custom phonetic tokenizers, stopword filtering, and n-gram vectorization.
- Trained multi-class classifiers to discern covert aggression (sarcasm/passive-aggression) from direct overt aggression.
- Built an interactive inference interface deployed on Streamlit Cloud for real-time text analysis.
